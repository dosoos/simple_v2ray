# 个人简易多节点VPN代理系统

## 项目介绍
当前项目是一个建议的vpn翻墙代理服务，使用django帮我制作一个简易的管理后台，
支持多用户管理，用户流量概览，可以跟其他节点的组成网状系统，同步流量跟用户，
以便在多个vps上可以快速搭建起节点，后台可以使用django自带的管理后台。
代理使用v2ray节点，前端使用caddy做https加密反向代理，集合本系统做管理。

## 功能列表
 - 用户管理，增删改查，订阅连接等
 - 用户流量管理, 查看用户流量使用情况，比如24小时，1周，1月，1年等，可自定义查询区间
 - 节点管理，节点之间可以互相加入，主节点收集同步用户数据，从节点同步主节点配置等
 - 其他系统功能

## 项目部署
项目使用docker部署，使用compose一键启动项目，通过环境变量加入主节点，默认是主节点独立服务器
